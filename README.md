# DJIOPKMNBVSCTTW

Live **XAU/USDT** perpetual terminal locked to the **15-minute** timeframe.

- Real-time price, mark, index, funding, and open interest
- 15m candlestick chart (200 candles) with EMA 8 / 21 / 50
- Order book, 7-factor signal engine, 6-gate validation
- Paste-signal monitor with SL / TP alerts
- Technicals, long/short ratio, taker volume

Not financial advice. Gold perpetual trading involves substantial risk.

## Run

```bash
npm install
npm run dev
```

Opens the terminal in the browser. Data is live public market data (OKX XAU-USDT swap + spot gold).
